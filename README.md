# Purchase Requisition System
1.About the Project:
This project is part of my BACT7501 Programming I Assessment 2. I developed a Purchase Requisition System using Python and Object-Oriented Programming (OOP).
The main purpose of this program is to manage purchase requests made by staff members. It can calculate the total cost of requested items and check whether a requisition is approved or pending.

2.Features:
My Purchase Requisition System creates a unique ID for each request and allows staff to add items with their prices. The program calculates the total cost and automatically approves requests below $500. If the total is $500 or more, the request stays pending until a manager approves or rejects it. The program also displays staff information, requisition details, and the total number of approved, pending, and not-approved requests.

3.How to Run:
Firstly, open the `requisition_system.py` file in VS Code then run the Python program and the program will display five sample requisitions with their approval details and statistics in the terminal.
